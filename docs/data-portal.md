# Repository and data portal

The [ECMonitor website](https://eco-website.pages.dev/) is the public entry point for browsing current monitoring records. Its [methodology page](https://eco-website.pages.dev/methodology/) describes the site's visible data model and scope. Site contents and totals may change as the database is updated.

This GitHub repository distributes the ECMonitor workflow source code and small illustrative files. The code release, the live site's data release, and the three published-literature examples have different scopes. Do not infer that every website record was generated by this source-code version, or that the example files are the website's complete dataset.

The runnable implementation is in [`harness/`](../harness/). The [literature examples](../examples/benchmark-instances/) provide background and formats for three published studies. Evaluation datasets and quantitative reconstruction results are not part of this source release.
